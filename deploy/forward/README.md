# ISL Bridge: tester link

This page forwards to the current address of the ISL Bridge test server, a two-way Indian Sign Language
conversation app built for the Meta Global AI Developer Hackathon. The server runs on the developer's laptop. When
the laptop is offline, the page waits and opens the app as soon as the server is back.

The address is updated automatically by `deploy/share.py` (last update: __UPDATED__).

Sign videos: ISL Dictionary, Indian Sign Language Research and Training Centre (ISLRTC) · INCLUDE dataset
(AI4Bharat, CC BY 4.0), signers of St. Louis School for the Deaf, Adyar, Chennai · CISLR (IIT Kanpur) ·
ISL-CSLTR (Elakkiya & Natarajan). Powered by Meta Muse Spark, Voice Transcribe and SAM 3.1.
